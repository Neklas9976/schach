# Third-party artwork and references

## chess.com-boards-and-pieces
The appearance picker catalog follows the board and piece directory names exposed by the public repository:
https://github.com/GiorgioMegrelli/chess.com-boards-and-pieces

This application does **not** redistribute those repository images inside the ZIP. When a style is selected, the browser loads the referenced image directly from the public GitHub raw URL. The repository README states that its `boards/` and `pieces/` directories contain boards and piece sets from chess.com; it does not provide a blanket license for redistribution of all those assets. Verify the rights of any specific asset before publishing or redistributing the application.

The app includes a local fallback piece set inherited from the project for offline use.
